## 2. Derivation Steps

### Step 1: From distinguishability to events

P1 + P2 → there exist **events**: distinguishable state transitions. An event is the primitive atom: "configuration A became configuration B."

**Audit:** No c, no space, no time assumed. Only difference and change.

### Step 2: From locality to ordering

P3 → events can be partially ordered. If event E₁ and E₂ occur at "the same place" (affect the same subset of distinguishable elements), they have a natural **before/after** relationship. If they affect disjoint elements, they are **spacelike separated** — neither is before the other in a local sense.

This gives us a **causal partial order** with no metric, no coordinates, no c. Just: A < B (A could influence B), A || B (spacelike), or A > B (B could influence A).

**Audit:** No c. No metric. Pure ordering.

### Step 3: From ordering to dimension

The causal set of events has a structure. The "thickness" of the light cone — how many mutually spacelike events can fit between two timelike events — defines the **spatial dimension**. For a causal set embedded in Minkowski spacetime, this number grows as r^(d-1) where d is the spacetime dimension.

**Key point:** Dimension emerges from counting, not from coordinates. No c needed.

### Step 4: From causal order to metric

If events are embedded in a continuous manifold (an **assumption**), the causal order alone determines the metric up to a conformal factor. This is the **Malament-Hawking-King-McCarthy theorem**: the causal structure of spacetime determines the metric up to a local scale factor.

Specifically: two metrics g and Ω²g produce identical light cones. The causal order gives you the light-cone structure, which is enough to determine the metric signature and the null geodesics. What remains undetermined is the **conformal factor** — the local scale of time and space intervals.

**c emerges here as the conversion factor between null directions.** In the light cone: dt² = dx² (in units where c=1). If we measure time and space in different units, c appears as the conversion. But fundamentally, c=1 — it's the statement that light cones have 45° slopes. The "speed of light" is **not a speed** — it's a geometric conversion factor arising from the metric signature.

## 4. Circularity Check

**c as 299,792,458 m/s is circular** — it's defined by the 1983 SI redefinition where the meter IS the distance light travels in 1/299,792,458 seconds. In this definition, measuring c means measuring the meter, and measuring the meter means dividing c by the cesium frequency. The SI system has made c definitionally circular.

**c=1 is NOT circular** — it's the statement that the metric has Lorentz signature. The only question is whether Lorentz signature can emerge from more primitive principles without assuming it.

**The metric signature problem:** Why (-,+,+,+) and not (+,+,+,+) or (-,-,+,+)? In causal set theory, the signature emerges from the counting of elements in the causal interval. The dimension and signature come from the same counting argument. But the causal set *itself* might have an emergent signature — we don't need to assume it.
