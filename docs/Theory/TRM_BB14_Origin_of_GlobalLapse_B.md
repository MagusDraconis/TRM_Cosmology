# BB14 — Physical Origin of the Global Lapse B(t)

## Context

CML01–CML23 established the following properties of B(t):

- global (CML15)
- instantaneous (CML17)
- fully observable (CML13)
- non-emergent (CML16)
- additive (not multiplicative scaling) (CML19, CML23)
- not removable by time-rescaling (non-gauge) (CML19, CML23)
- observer-independent (CML20)
- acts as a universal reference clock (CML21)
- history-independent (no hysteresis, no memory) (CML22)

---

## Core Result

B(t) is:

- not a local field
- not a transport quantity
- not emergent
- not gauge
- not dependent on system dynamics

Therefore:

B(t) must originate from a structure external to the oscillator system.

---

## Problem Statement

What physical mechanism can generate a quantity with the following properties:

- affects all degrees of freedom equally
- has no spatial variation
- exhibits no propagation delay
- has no internal dynamics or feedback
- is directly measurable via frequency shift
- is not removable by coordinate transformation

---

## Candidate Classes

Evaluate only mechanisms structurally compatible with the above constraints.

---

### Class A — Cosmological Time Background

Interpretation:

    B(t) reflects a global time-rate evolution of the universe

Examples:

- cosmological scale factor a(t)
- global clock drift / background time curvature

Key test:

    Does B(t) couple universally and instantaneously
    without spatial dependence?

---

### Class B — Global Constraint / Boundary Condition

Interpretation:

    B(t) arises from a global constraint imposed on the system

Examples:

- boundary condition in action principle
- normalization constraint on phase evolution

Key feature:

    no propagation (constraint applies everywhere simultaneously)

---

### Class C — External Absolute Time Field

Interpretation:

    B(t) is a fundamental background variable
    independent of all dynamical fields

Constraints:

- not derivable within existing field theory
- not coupled locally
- defines time-rate directly

---

### Class D — Effective Reduction Artifact (to test against)

Interpretation:

    B(t) emerges from coarse-graining
    but appears global

Rejection criteria:

- must explain why it cannot vary spatially
- must explain absence of memory (CML22)
- must explain instant response (CML17)

---

## Evaluation Criteria

Each candidate must satisfy ALL:

- global uniformity (CML15)
- zero propagation (CML17)
- no emergence (CML16)
- no hysteresis (CML22)
- universality across observers (CML20)
- additive frequency shift (CML19, CML23)

Reject candidate if any criterion is violated.
