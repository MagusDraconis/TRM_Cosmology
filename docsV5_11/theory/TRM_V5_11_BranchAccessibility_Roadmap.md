# V5.11 Branch Accessibility Roadmap

**Central question:** Why are Hi→Lo transitions persistently accessible while Lo→Hi persistent transitions are not?

**Hypotheses:**
1. Basin asymmetry: High→Low is down-gradient, Low→High requires barrier crossing
2. Intervention mismatch: Suppressor follows natural trajectory; inducer must reverse it
3. N-window: Accessibility changes near transition N (N=71)
4. Structural lock-in: Low-branch K-state is an attractor basin

**Decision gates:**
- Gate A: Accessibility is basin-asymmetric
- Gate B: Accessibility is N-window dependent
- Gate C: Barrier can be quantified
- Gate D: Accessibility is structural
